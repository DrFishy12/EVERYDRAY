# EVERYDRAY

פלטפורמה למדריכות פילאטיס: בניית שיעור מאפס ממאגר של מעל 120 תרגילים (עם הדמיה, הסבר מפורט וקישור לסרטון),
סידור השיעור מההתחלה ועד הסוף, שיבוץ בלוח שנה מסודר, ועוזרת AI בצ'אט.

האתר באוויר: <https://everydray.fit>

## מבנה הקבצים

| קובץ | תפקיד |
|---|---|
| `index.html` | מבנה העמוד |
| `style.css` | עיצוב |
| `exercises.js` | מאגר התרגילים |
| `demos.js` | אנימציות ההדמיה של התרגילים |
| `app.js` | בניית שיעור, השיעורים שלי ולוח השנה |
| `chat.js` | צ'אט ה-AI (הכפתור העגול בפינה הימנית התחתונה) |
| `config.js` | הגדרות, כולל כתובת שרת ה-AI |
| `ai-proxy/` | שרת קטן (Cloudflare Worker) שמחבר את הצ'אט ל-Claude |

## צ'אט ה-AI

בלי הגדרות, הצ'אט עובד ב"מצב בסיסי" ועונה מתוך מאגר התרגילים.
כדי להפעיל AI מלא עם Claude, ראו את ההוראות ב-[`ai-proxy/README.md`](ai-proxy/README.md).

כל הנתונים (שיעורים, לוח שנה, היסטוריית הצ'אט) נשמרים בדפדפן של המכשיר. אפשר להעביר אותם בין מכשירים
דרך "הורדת גיבוי" ו"ייבוא גיבוי" במסך "השיעורים שלי".
